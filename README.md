# FairViT-Med — Fairness-Aware Vision Transformer for Medical Diagnostics

This project builds a Vision Transformer (ViT) model for medical image classification with a focus on fairness across demographic groups.

## Objective
To ensure equitable diagnostic performance across protected attributes such as sex, while maintaining high accuracy.

## Dataset
NIH ChestX-ray14

## Key Components
- Vision Transformer (ViT)
- Fairness evaluation (TPR, accuracy by group)
- Bias mitigation techniques
- API deployment using FastAPI
